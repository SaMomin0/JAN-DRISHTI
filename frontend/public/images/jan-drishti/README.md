# JAN-DRISHTI Image Assets Directory

Place your custom webp/png/jpg images in this folder matching the following names:

- `hero-background.webp` (Hero section visual background)
- `platform-overview.webp` (Platform introduction preview image)
- `risk-case-preview.webp` (Risk case section preview image)
- `intelligence-workflow.webp` (Intelligence workflow diagram)
- `evidence-network.webp` (Evidence graph overlay visual)

The UI will automatically render your images as soon as they are placed here, with built-in CSS/SVG dark placeholders if an image file is not yet provided.
